# ResumAI – AI-Powered Resume Analyzer

ResumAI is an AI-powered resume analysis tool that helps users evaluate how well their resumes align with a given job description. It extracts information from uploaded PDF resumes, identifies relevant skills, highlights missing skills, calculates a skill match score, and generates AI-based recommendations to improve the resume.

The project combines Python-based skill analysis with Google's Gemini API to provide useful feedback and help job seekers better understand their suitability for a particular role.

## Features

- **PDF Resume Upload:** Upload your resume in PDF format for analysis.
- **Resume Text Extraction:** Automatically extracts text from uploaded PDF files.
- **Skill Detection:** Identifies technical and professional skills mentioned in the resume.
- **Job Description Analysis:** Extracts required skills from the provided job description.
- **Skill Matching:** Compares resume skills with job requirements.
- **Match Score:** Calculates a percentage-based score representing skill coverage.
- **Missing Skills Identification:** Highlights skills required by the job description that are not detected in the resume.
- **AI-Powered Recommendations:** Uses Google's Gemini API to generate personalised feedback and suggestions.
- **Interactive Interface:** Provides a simple web interface for uploading resumes and viewing analysis results.

## Tech Stack

 Python, Flask, HTML, CSS, JavaScript, PyMuPDF, Google Gemini API, Python-Markdown, python-dotenv
